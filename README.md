# Arrays & Strings

A from-scratch beginner project that turns "I know what an array is" into "I can reach for the right pattern on demand." Step by step you grow a tested Python toolkit covering two pointers, the sliding window, prefix sums, in-place mutation, and string manipulation — each as a small module with pytest tests and a README. The Socratic dialogue teaches the WHY behind every pattern and its time and space complexity, so you can derive the right approach under pressure instead of memorizing solutions.

## Stack
- Python
- pytest
- Arrays
- Strings
- Big-O
